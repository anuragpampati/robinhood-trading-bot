## Step 3b — Update ATR trailing stops
Read docs/positions.json. For each equity position, get current_price via get_equity_quotes:
  entry_atr_pct = position.entry_atr_pct (default 0.02)
  initial_stop  = avg_cost × (1 − 2.0 × entry_atr_pct)
  current_stop  = position.trail_stop (default initial_stop)
  profit_pct    = (current_price − avg_cost) / avg_cost

  Ratchet UP only:
  - profit_pct ≥ 0.050: new_stop = max(current_stop, avg_cost × 1.025)
  - profit_pct ≥ 0.025: new_stop = max(current_stop, avg_cost × 1.005)
  - else:               new_stop = current_stop

## Step 3c — Circuit breaker check (soft, resets daily/weekly)
Read docs/positions.json (prior). Compute:

  account_value = buying_power + sum(equity pos values)
  now_et_date   = current date in America/New_York timezone, format YYYY-MM-DD
  now_weekday   = day of week (Monday=0, Sunday=6)

  if prior.day_start_date != now_et_date:
      day_start_value = account_value; day_start_date = now_et_date
  else:
      day_start_value = prior.day_start_value (default: account_value)
      day_start_date  = prior.day_start_date

  if now_weekday == 0 and prior.week_start_date != now_et_date:
      week_start_value = account_value; week_start_date = now_et_date
  else:
      week_start_value = prior.week_start_value (default: account_value)
      week_start_date  = prior.week_start_date (default: now_et_date)

  peak_value = max(prior.peak_value if prior.peak_value else 250.0, account_value)

  daily_dd  = (day_start_value  - account_value) / day_start_value  if day_start_value  > 0 else 0
  weekly_dd = (week_start_value - account_value) / week_start_value if week_start_value > 0 else 0
  circuit_breaker_active = daily_dd >= 0.03 or weekly_dd >= 0.05

  If circuit_breaker_active:
    Append: "⛔ CIRCUIT BREAKER — daily {daily_dd:.1%} / weekly {weekly_dd:.1%} — ALL NEW BUYS HALTED"
    Skip Step 4b entirely.
